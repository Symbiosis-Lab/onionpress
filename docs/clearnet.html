Put Your OnionPress Site on a Custom Domain

Your OnionPress site already has a permanent .onion address that works in Tor Browser and Brave. If you also want it reachable at a regular domain like www.example.com, you can set up a free Cloudflare Tunnel to connect the two.
Privacy Note: Your .onion address keeps your server location hidden. A clearnet domain with Cloudflare Tunnel reveals your Mac's IP address to Cloudflare. Your .onion address continues to work either way.

What You Need

  • OnionPress running on your Mac
  • A domain name you own (e.g. from Namecheap, Cloudflare Registrar, etc.)
  • A free Cloudflare account

Setup Steps

1 Add Your Domain to Cloudflare

  1. Log in to dash.cloudflare.com
  2. Click Add a site and enter your domain (e.g. example.com)
  3. Select the Free plan
  4. Cloudflare will scan your existing DNS records. Review them and click Continue.
  5. Cloudflare gives you two nameservers (e.g. anna.ns.cloudflare.com). Go to your domain registrar and replace the existing nameservers with these two.
  6. Back in Cloudflare, click Done, check nameservers. It can take up to 24 hours for nameservers to propagate, but usually it's a few minutes.

2 Create a Cloudflare Tunnel

  1. In the Cloudflare dashboard, go to Zero Trust (left sidebar)
  2. Navigate to Networks → Tunnels
  3. Click Create a tunnel
  4. Choose Cloudflared as the connector type
  5. Give your tunnel a name (e.g. onionpress) and click Save tunnel

3 Copy the Tunnel Token

After creating the tunnel, Cloudflare shows an install/run command like:

cloudflared service install eyJhIGxvbmcgand0Li4u

The long string at the end is your tunnel token. Copy just that token (not the whole command).

4 Set the Public Hostname

Still in the tunnel setup page:

  1. Click the Public Hostname tab
  2. Click Add a public hostname
  3. Set Subdomain to www (or leave blank for the root domain)
  4. Set Domain to your domain (e.g. example.com)
  5. Under Service, set:
    • Type: HTTP
    • URL: wordpress:80
  6. Click Save hostname
Why wordpress:80? The Cloudflare tunnel agent runs inside Docker alongside WordPress. wordpress is the container name on the internal Docker network. Cloudflare handles HTTPS for visitors automatically.

5 Paste the Token in OnionPress

  1. Click the OnionPress icon in your Mac's menu bar
  2. Click Settings
  3. Paste your tunnel token into the Cloudflare Token field
  4. Click Save
  5. OnionPress will restart to activate the tunnel

6 Verify It Works

After OnionPress restarts, open your domain in any browser:

https://www.example.com

You should see your WordPress site. The menu bar will show "Clearnet: Active (via Cloudflare)".

FAQ

Does this cost anything?
The Cloudflare Tunnel and Cloudflare DNS are free. You only need to pay for the domain name itself (typically $10-15/year).
Does my .onion address still work?
Yes. The clearnet domain is an additional way to reach your site. Your .onion address and Wayback Machine fallback continue to work exactly as before.
What happens when my Mac is asleep or off?
The clearnet domain will show a Cloudflare error page. Your .onion address will fall back to the Wayback Machine archive (if enabled). To keep the clearnet domain available, keep your Mac awake and OnionPress running. The "Prevent Sleep" setting in OnionPress can help with this.
Can I use the root domain (example.com) instead of www?
Yes. In Step 4, leave the Subdomain field blank to use the root domain. You can also add both the root and www as separate public hostnames pointing to the same tunnel.
Can I remove the tunnel later?
Yes. Clear the Cloudflare Token field in OnionPress Settings and restart. The tunnel stops and your site goes back to .onion-only access.
Is my site's traffic encrypted?
Yes. Cloudflare provides HTTPS to visitors automatically. The connection from Cloudflare to your Mac goes through an encrypted tunnel. You do not need to set up SSL certificates yourself.
Can someone find my Mac's IP address?
Cloudflare acts as a reverse proxy, so visitors see Cloudflare's IP, not yours. However, Cloudflare itself knows your IP (the tunnel connects to their edge). If IP privacy is critical, stick with the .onion address only.
I already use Cloudflare for my domain. Will this conflict?
No. The tunnel creates a CNAME record for the hostname you choose. Your other DNS records are unaffected.
